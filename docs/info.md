## How it works

A D flip-flop is a digital storage element that holds one bit of information. It operates as a clock-driven sequential circuit, meaning its output updates only in response to a clock signal. When the clock makes a rising-edge transition, the flip-flop samples the value at the D input and stores it, maintaining that value until the next triggering clock edge.
